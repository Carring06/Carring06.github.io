可调电源2.0改版说明

  首先，原版的可调电源1.0采用的是PCB四层板结构，四层分别为：顶层信号层，内层1-PWR层，内层2-GND层，以及底层信号层。因为那时候的我，第一次画四层板，其实是处在一个朦胧的状态中，那时候只知道四层板绘制，可以多两层来走线，但是没有在意太多其他的细节，比如说，电流的回流路径长，没有合理的参考地，没有考虑到开关芯片噪声会耦合进公共地上等等。拿我顶层走线来说，顶层的电流要回到地，就必须先通过过孔到达内层1，然后再经过过孔到达地平面，这样造成的影响就是，电流的环路面积变大，还可能导致寄生电感大幅增加，而且流经PWR层后，也可能会耦合其他电源线的噪声，关于寄生电感增加，我们知道，公式 U = L * di/dt，但开关导通或者关闭瞬间，di/dt会很大，寄生电感会感应出高压尖峰，这样会导致陶瓷去耦电容的作用被削弱，来不及吸收尖峰，电源轨上噪声明显，容易干扰单片机、ADC 采样，甚至可能击穿元器件。
  针对于上述“顶层的电流要回到地，就必须先通过过孔到达内层1，然后再经过过孔到达地平面”，其实这句话严格上来说是不太严谨的。因为我在顶层和底层也有铺地铜，其实电流是可以在顶层形成回路的。但是，部分高频开关噪声更愿意走阻抗小，环路最小的回路，也就是通过过孔走到内层2。抛开这个问题不谈，我们也可以假想一下，电流流向顶层/底层的GND时，噪声是会耦合在公共地的，这样MCU部分自然会受到噪声的强干扰，所以无论电流是走向内层2好，还是说直接在顶层/底层回路也好，都会造成一些不好的影响的。
  所以，综合已存在的问题，我决定将可调电源2.0设定为六层板结构。六层分别为：顶层信号层，内层1-SGND1层，内层3-PWR层，内层4-PGND层，内层5-SGND2层，以及底层信号层。首先，这里先说明一下，SGND层以及PGND层具体代表什么。SGND表示的信号地层—单片机等电路的参考地，PGND表示的是开关芯片的功率地层。然后，在PCB绘制完成后，在顶层/底层铺铜选择的是SGND（因为SGND耦合的开关噪声最小）。其中，功率地和信号地采用的是0Ω电阻进行连接的方法。
  接下来说一下，当前的改动具备哪些优点。首先，和 1.0 很明显的一个区别就是，2.0 采用了双地策略，也就是将信号参考地以及功率参考地分开，然后用一个 0Ω 电阻单点连接。这样既保证两个参考地直流等电位，又能阻止开关电源的大功率噪声扩散到信号地。主控信号的参考地电位更加平稳，地弹波动更小；其次，本次采用六层板结构，把电源层放置在 SGND 与 PGND 两层地平面之间，利用上下地平面做屏蔽，隔绝 PWR 层噪声通过层间耦合串入顶层 / 底层的信号线；而且，在六层板的结构中，有3层GND铺铜层，这样可以通过过孔带走TPS5450，XL6019功率芯片的热量，这样能减少一下带负载时板子发热过烫的现象。
  除此之外，顶层和底层的信号线包裹在相对于稳定的SGND铜皮里面，信号的抗干扰能力会更强。四层板的GND耦合的噪声太大，信号线包裹在其中会没有“安全感”的，然后就导致信号杂乱起来了，这是对我1.0板子存在的异常进行的假想说明与改动，真正结果和缘由还得等进行测试后才得知。
  异常可以观看：基于嘉立创专业版设计的可调电源1.0-哔哩哔哩视频展示 或者 BUG前瞻序言 。
  但其实对于那几个电容焊接上去后板子就异常的这个问题，我并没有做出有力的改动，只能做一下增大一下电容与芯片的距离等小改动了，这个也要等待后续测良了。
