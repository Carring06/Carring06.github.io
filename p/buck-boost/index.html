  这个章节主要是来讲一下BUCK电路和BOOST电路的一些基础知识的，其实这一部分内容，大家有稍微了解一下便是可以的。对于我，因为我先前也只是对这部分进行视频学习，学习后并没有做任何反馈，所以导致的问题是，我对这部分掌握的并不是太彻底。也就是说，在写这篇文章前，我仅仅只对这部分知识点进行了“输入”，并没有进行“输出”。所以，为了加深我个人对BUCK-BOOST电路的理解，我打算重新学习这一部分，并将其进行总结。各位也可以对其进行学习了解一下，如若有错请在评论区严肃指出！

LDO与DCDC

  LDO（Low Dropout Regulator）是一种降压型稳压器，它通过将输入电压降低到一个固定值来输出稳定的电压。而DCDC（Direct Current to Direct Current Converter）是一种直流到直流转换器，它通过将输入电压转换为一个不同的电压来输出稳定的电压。
  LDO作为线性稳压器，只能进行降压而不能进行升压，而DCDC既可以升压也可以降压。我们需要知道的是LDO是将多余电压直接消耗，转化为热量，而 DCDC 是通过电子开关的开关频率来进行升压降压的。在实际电路中，倘若要进行降压的压差较大，那么LDO的发热会很严重，在我先前的平衡车中，我的AMS1117芯片就因为发热而烧毁了（用手触摸芯片，手会直接条件反射缩回）。
  Buck、Boost 专指 DCDC 的拓扑结构，LDO 不属于这一类。所以接下来的BUCK-BOOST均是针对DCDC开关电源讲述的。

BUCK电路


  如图是一个BUCK电路，其中M1为MOS管（至于是NMOS还是PMOS，这里暂不进行探讨），大家可以将其理解成一个电子开关，这个开关的闭合与打开是通过电信号控制的。为了便于分析与理解，我将其换成一个普通开关，如下图所示。

  在分析这个电路前，我们要先知道两个公式：i = C*(du/dt)与u = L*(di/dt)。这两个公式，很好地反映了电容与电感的特性——电容两端电压不能突变，电感两端电流不能突变。也就是说，使用电容电感，有个很重要的作用是能用来抑制上电时的浪涌电压与浪涌电流!所谓的浪涌电压，浪涌电流，指的是短时间突然爆发，远超正常额定值的电压/电流。这里提一嘴，如果遇到不懂的知识点，可以问一下AI进行粗略的了解，倘若想继续深究，再去网上找一些资料进行补充学习，这个方法是适配与任何新手的（Me也是）。
  既然提到了这两个公式，那我也顺便来以我的见解来分析一下电容电感具有抑制电压/电流突变的原因，以下为个人见解，如若有错，欢迎指出!
  对于电容相关公式i = C*(du/dt)：正常来说，刚上电的时候，负载两端电压会在短时间内从零骤变成我们的上电电压，而对于电容来说，我们假设电容两端的电压也会阶跃突变（时间趋近于 0），那么，电容的U-t特性曲线的斜率，也就是du/dt的值会无穷大，对应的电流i = C*无穷大 = 无穷大，也就是说，如果我们的假设成立的话，那么电路中的电流理应是无穷大的，但是在实际中，电路中的电流是不能也不会无穷大的，那么可以反推出，我们的假设不成立。那么可以推出，电容两端的电压是不能突变的。所以，有了这个特性，我们就可以在负载两端并联个电容，来抑制浪涌电压。
  对于电感相关公式u = L *(di/dt)，我们按照上一段的逻辑分析一下，也可以得出结论：流经电感的电流是不能突变的。因此，我们可以在电路中串上一个电感，来抑制浪涌电流。
  当然，BUCK电路中的电感电容，也是有应用以上论述的功能的，而且，还有利用电感电容的另一个重要特性：储能!
  当开关闭合时，电流流动方向如上图蓝色箭头所示。因为在从a点流向b点过程中，电流流经一个电阻，此时电势会下降，所以a点电势高于b点。所以电流是不会从b点倒流至a点的。
  当开关打开时，输入部分的电路不用去分析，直接看后面电路。前文中，我们也有提到，在这个电路中，我们使用用到了电容电感的储能特性。如上图所示，当开关打开时，因为电容电压电感电流不能突变，所以，即使没有电源输入，电路中的电流电压是不会立马变为0的，以电感为例，此时的电感相当于一个电源，还会向电路提供电流，电流方向如图所示。二极管的存在，就是给电感电流一个续流的回路，所以称他为续流二极管。也许有人会觉得，为什么还要多加个元器件，为什么不让电流直接流向参考地就好了？ 这里提一嘴，就是，如果不给电感一个续流的回路，那么当电感要释放电流时，会发现压根没有回路可以走电流，没有回路走电流的话，电流只能为0了，而由公式u = L *(di/dt)，电流在较短时间变为0的话，di/dt很大，会感应出一个很大的电压，这个电压也许会大到击穿MOS管。所以综合上述分析，是应该给电感释放电流的回路的，而结合二极管的单向导电特性，我们不难发现，使用二极管放置在电感续流路径，是一个较好的选择，当然，二极管也并不是唯一或者说最优的元器件选择，当前图中的BUCK电路，使用的是续流二极管，那么我们称他为异步BUCK。倘若我们将这个二极管换成另一个MOS管，那么就称之为同步BUCK，同步BUCK可以降低续流时候的损耗，提升电源效率，但对应的芯片电路就会更复杂，成本会更高。

  上述我们好像只是论述了电路相关的，并没有说明是如何实现降压的。那我这里就来简单说明一下（网上教学视频很多，这里就不过多论述）。我们说过，MOS管是个电子开关，在我目前学习过的，大多都是通过输出PWM波来控制MOS管的导通与断开，在很多的开关芯片里，会将PWM的频率称之为开关频率，在绝大多数情况下，开关频率越高，该开关芯片输出的电压会更好，电压纹波会更平滑（这个PWM波是芯片自身生成的，并不需要我们进行PWM生成操作，不过，万一呢…[手动狗头]）。但其实开关频率并非越高越好，频率提升会增大开关损耗与电磁干扰。

  回归正题，在此电路中，当开关闭合时，电流会缓慢上升，电容会缓慢充电；而当开关打开时，电感和电容会进行放电。所以，只要我们控制好开的时间和关的时间，就能控制充放电的时间，而当我们能控制好充放电的时间，那我们也就能输出的电压值（充电时间久，放电时间短，那么输出的平均电压就高；反之则低）。而这里就有涉及到一个新的概念，就是占空比D。在BUCK电路中，占空比D = Ton / T总 = Vout / Vin（其实这么说好像不太准确，好像这个公式仅适用于 CCM，具体大家可以去看看–>电路小匠<–的讲解，后续我也会再进行二刷三刷，然后再来总结一下）。由公式D = Ton / T总 = Vout / Vin，我们可以根据已知的输入电压以及目标输出电压来求解占空比。一般来说，开关芯片的开关频率在芯片手册上是有给的，进而可以由频率算出周期T总，再加上已知占空比，我们可以计算出开关闭合时间Ton（这个好像可以在DEBUG时用示波器来查看一下）。好吧，啰里啰唆说了一堆，但其实这些都只是理论知识，大家可以进行学习了解一下。在实际画原理图中，其实主要是参考数据手册画的，这一部分只作为补充了解，了解的话更好，不是那么懂也别太担心，大多数情况下，跟着原理图走就行！

BOOST电路

  上图，是BOOST电路的电路图，我们同样用一个普通开关替换MOS管，以来更简洁的分析。
  当开关闭合时，如上图所示，蓝色箭头表示电流方向，后面电路被开关那一路短路。闭合期间，电感进行了储能，左边感应出正电压，右边感应出负电压。开关闭合的时间越长，电感也会随着储存更多电能量（在储能最大限制内）。而在二极管右侧，电容两端在先前的开关打开状态的时候，进行了充电，当不再有电流过来时，电容会进行放电，电流方向如上图绿色箭头所示，这样可以短暂维持输出电压，但随后也会逐渐降低
  开关闭合时，该回路中并没有经过负载，所以流经电感的电流会比较大，此时电感是左端感应正电，右端感应负电，而当开关打开时，原先的回路断开了，此时电流就必须流经负载，有了负载，电流就不会和原先一样大了，所以电流有变小的趋势，但是电感存在，就是阻止电流突变，而在此电路中，阻止电流突变的唯一的方法就是增大回路电压，所以电感只能反转两端的正负性，此时，电感变成了左负右正，此时的电感可以看成另一个电压源，他和电源进行了串联，此时回路的总电压就会增大，进而达到阻止电流突变的效果。此时电感电压和电源电压都叠加在负载上，那么输出的电压就会比原先单个电源的电压大，进而达到了升压效果。
  所以，要控制输出电压的大小，就要控制电感两端的电压，要控制电感两端的电压，就要控制好电感的充电放电时间，即控制好开关的闭合与打开时间。当开关闭合的时间越长，打开时间越短，电感两端的电压就会越大,输出电压就会越大；反之越小。
