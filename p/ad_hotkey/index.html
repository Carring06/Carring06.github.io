数据来源：DXP.RCS（Altium Designer 的键位变更日志），由 AD快捷键.json 转换；本表只做“键位 → 作用”的速查。 主键 = Shortcut1，备用键 = Shortcut2；同一命令改过多次时以最后一次为准。

常用 PCB 绘制快捷键（先看这张）

  日常画板按得最多的 20 个键，记住这张就够开工；带 〔自定义〕 的是改过键位的，其余为 AD 默认。

键位 作用 备注
Ctrl+W 交互式布线 最常用的起手键
W 快速布线 〔自定义〕备用键；原理图里 W 是放置导线
Alt+D / F3 快速差分对布线 〔自定义〕主 / 备
V 放置过孔 〔自定义〕；默认仍可用 P»V
F2 放置多边形铺铜 〔自定义〕；菜单里仍是 P»G
Shift+B 重新铺设全部铺铜 〔自定义〕改完线一键重铺
+ / -（小键盘） 切换到下一层 / 上一层 换层最快的键
Shift+S 单层显示 / 多层显示 切换 看单层时必按
L 打开视图配置（层与颜色） 双击层标签色块可改色
2 / 3 切到 2D / 3D 视图 回 2D 也用它
Q 单位切换 mm ↔ mil 规则对话框里要用 Ctrl+Q
Shift+R 切换走线模式（正交 / 45° / 任意角） 状态栏可确认当前模式
Shift+E 循环捕捉模式（关 / 当前层 / 全部层） 状态栏应显示 Hotspot Snap (All Layers)
Shift+Z 元件区域放置
T+C 元器件交叉选择 原理图到PCB/PCB到原理图
Ctrl+M 测量距离 测前先 Ctrl+E 勾 Pad Centers
Shift+C 清除过滤 / 取消高亮 高亮网络后用它退出
Ctrl+H 选中相连铜皮 整套网络一次选中
6 / 7 线选 / 区域框选 〔自定义〕改单根 / 圈一片
Shift+Ctrl+L / R / T / B 左 / 右 / 顶 / 底 对齐 配合 Shift+Ctrl+H / V 等间距
Ctrl+Num4 / 6 / 8 / 2 左 / 右 / 上 / 下 移动 500mil 精确挪位不用鼠标
T D R 批量设计规则检查（DRC） 出图前必跑

一、一页速查（按使用频率）

键位 作用 适用 什么时候按 槽位 备注
F2 放置多边形铺铜 PCB 布线后期铺 GND / 电源铜皮 备用键 菜单里仍是 放置(P)»铺铜(G)
Shift+B 重新铺设全部多边形铺铜 PCB 改完走线、铜皮没刷新时一键重铺 备用键 不用逐个点重铺
6 线选（选中碰触的走线/对象） PCB 改单根走线、只选相连的一段 备用键 比框选精准，但要多点几下
7 区域框选（选中区域内对象） PCB 整块电路一起选中、批量挪动 备用键 和 6 成对使用
V 放置过孔 PCB 换层、打地过孔、补缝合孔 备用键 抢了 视图(V) 弹出键，视图菜单用 Alt+V
Shift+Z 在矩形区域内排列器件 PCB 刚导入 PCB、器件堆成一坨时先码齐 备用键 先框选器件再按
Shift+W 交换器件 PCB 两个器件位置对调 备用键 布线进行中仍是切走线宽度
W 快速布线（PCB） PCB PCB 里开走线，比 U 菜单快 备用键 与原理图的 W 互不干扰
Alt+D / F3 快速差分对布线 PCB USB、以太网等差分对一次拉两根 主键 / 备用键 主 Alt+D，备 F3
W 放置导线（原理图） 原理图 原理图连线，起手就按 主键 仅在原理图编辑器生效
Q 设计菜单某子项的弹出键 全局 键盘呼出设计菜单下的某一项 菜单弹出键 具体是哪一项待核对

三、键位占用与冲突（重要）

键位 情况 怎么办
V 抢了 视图(V) 菜单的弹出键 视图菜单改用 Alt+V，永远可用
Shift+W 布线进行中归走线引擎（切换线宽） 只有不在布线状态时才触发「交换器件」
W 原理图 = 放置导线；PCB = 快速布线 两个编辑器各自独立，互不干扰
F2 只绑给「铺铜」，不是通用键 别把它当“重命名 / 确认”用
Q 是菜单弹出键，不是命令键 具体子项需在 Customize 里核对

五、想再加一个键

  1. 菜单栏空白处右键 → Customize… → 命令列表选 ALL；
  2. 找到目标命令，Ctrl+单击 打开 Edit Command；
  3. 主要的 填主键、可选的 填备用键；确认下方 当前被用于: 为空（否则说明被占用）；
  4. 回 PCB 实测一遍，再重新导出 DXP.RCS 更新本表。
