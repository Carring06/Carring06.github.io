一、快捷键与软件操作基础

  很多人用 AD 是"菜单点到底”，其实这软件的键盘设计有一套完整的逻辑。先把它想明白，后面所有操作都能加速。

1.1 三段式加速键：AD 的键位是一门"语言"

  AD 的加速键（Accelerator Keys）不是同时按，而是一个字母一个字母地连按，沿着菜单层级往下走。第一段是主菜单的"弹出键"，第二、三段是子菜单和命令的首字母。比如 T D R 就是工具(Tools) → 设计规则检查(Design Rule Check)，D R 是设计(Design) → 规则(Rules)。

主菜单 弹出键
File / Edit / View F / E / V
Project / Place / Design C / P / D
Tools / Route（仅 PCB） T / U
Reports / Window / Help R / W / H

1.2 想不起快捷键时怎么办

  不用背。AD 留了三个"现场查号台"，其中最快的是在执行命令的过程中按 Shift+F1：它会弹出一个小菜单，把这个命令当前阶段所有可用的键位全列出来，看完按 Esc 关掉，命令照旧继续，不会被打断。

  要通览全部命令，就在菜单栏或工具栏的空白处点右键，选 Customize...，在弹出的命令列表里选 ALL 分类，一条条命令和它当前绑定的键位都会列出来。

1.3 改键：给高频操作安排一个顺手的位置

  改键有两条路，都很直接：

  路径一（推荐）：在任意菜单项或工具栏按钮上按住 Ctrl 再单击，直接弹出 Edit Command 对话框。对话框里 处理(E) 和 参数(P) 是系统 ID 与执行参数，不要动；真正要填的是下半部分的"快捷键"区——主要的 填主键，可选的 填备用键。

  上图里 主要的 / 可选的 两栏是空的，下面两行 当前被用于: 也是空的——这表示这个命令目前没有绑定任何键，可以放心填。

  路径二：先按 Alt 让菜单显示带下划线的加速键字母，再用鼠标点到目标命令。

  改完一定要看 当前被用于: 有没有冒出别的命令名——那说明这个键已经被占用，继续绑定会把原命令的键抢走。

1.4 键位冲突：AD 里最常见的一次"撞车"

  AD 的菜单项右侧会显示该项的快捷字母。素材里被红框圈出的 放置(P)»过孔(V)，字母就是 V；而 视图(V) 菜单的弹出键同样是 V——两个高频入口挤在同一个键上，这就是 AD 里最典型的一次键位撞车。

  处理原则很简单：保留高频、让低频换位——把常用操作从"两段式"降级成"单键/功能键"，把双字母序列留给低频但系统的命令。上面这张图里的 V 就是我自己动手改的：把 放置»过孔 的备用键设成 V，让单键直达过孔；代价是 视图(V) 的弹出键被抢了，但主菜单永远可以用 Alt+V 精确进入，所以并不吃亏。

  改完记得回 PCB 里实测一遍：键位不冲突只是必要条件，顺手才是目的。我这套键位最后到底改成了什么，本章最后一节（1.7）直接给完整清单。

1.5 面板与视图：先把"看"的问题解决

  AD 的面板有二十来个，一个个从菜单里找太慢。所有面板都从界面右下角的 Panels 按钮出，点开就是勾选清单，勾上就浮出来，再点一下收起。

  几个必备面板：Projects（工程树）、Properties（属性，选中什么就显示什么）、PCB（网络/器件/差分对/联合体）、PCB List（批量编辑，ROOM 一节的主角）、Messages（编译与 DRC 报告）。

  视图操作的固定套路：东西找不到了，先 V D（适合文件）或 V F（适合板子）；只想盯一层，Shift+S 切单层；要看某层的颜色，L 打开 View Configuration，双击层标签的色块就能改色——这部分在第 8 章《层叠、板框与负片》细讲。

1.6 吸附：为什么你的光标"不听话"

  这是新手最容易怀疑人生的一处。明明把光标放在焊盘正中心，测出来的距离却差一点；明明想画到 100mil 的整数位置，线就是吸不上去。原因几乎都在**捕捉（Snap）**的设置上。

  Shift+E 在三种模式间循环：Off（关闭）、Current Layer（只捕当前层）、All Layers（所有层都捕，推荐）。判断是否生效只看一个地方——状态栏右下角，显示 Hotspot Snap (All Layers) 才是对的。

  更细的开关在 Ctrl+E 打开的捕捉选项里：Pad Centers（焊盘中心，测中心距必开）、Pad Edges（焊盘边缘，测边到边）、Via Centers、Intersections、Track/Arc Vertices 等，按需勾选。没勾 Pad Centers，就算开了 All Layers，光标也不会跳到焊盘中心——这句话值得抄在便签上。

二、元件库与封装

  画板的第一个分水岭在这里：库里没有的器件，你是选择"从零画"，还是"想办法弄到"？ 我现在的答案永远是后者——AD 提供了四条"抄"的路径，能省掉 90% 的手工劳动。

2.1 元件库的四条来源

2.1.1 路径一：从原理图反向生成符号库

  拿到别人画好的原理图，想复用里面的器件，只要执行 设计»生成原理图库(M)，整个工程的器件就会被抽成一个 .SchLib，符号、引脚、参数一并带出。

2.1.2 路径二：从 PCB 反向生成封装库

  别人的板子画好了，封装你不必重画——设计»生成PCB库(P)，快捷键 D P，整板封装会被抽成一个 .PcbLib，再复制粘贴到自己库里就行。

2.1.3 路径三：用标准封装向导生成

  SOIC、SOP、QFP 这类标准封装，工具»IPC Compliant Footprint Wizard 会按 IPC 标准一步步问你尺寸，最后直接生成带焊盘、丝印、装配层的完整封装，比自己画准得多。

2.1.4 路径四：查尺寸图自建

  冷门封装只能自己来，但不必靠猜。像 IC 封装网这类站点会按型号给出封装尺寸图（例：SOP-20_300mil 的 e=0.050in、B=0.016in），但最终一定要回到厂商 datasheet 核对，第三方站点只当索引用。

  还有一种"偷懒"的极致：直接下载别人打包的超级库——2D 标准封装库 + STEP 3D 库 + 官方集成库，一次几十上百兆，覆盖大部分常用器件。代价是质量参差，用之前得抽检几个关键封装。

2.2 封装管理器：一处改完全工程

  元件散落在十几页原理图里，一个个双击改封装会疯。工具»封装管理器(G) 会把整个工程所有元件及其封装列成一张表，可以批量指定、批量替换、批量检查"哪个元件还没封装"。

  这张表也是导入 PCB 之前必须过一遍的地方——后面 Footprint Not Found 的报错，十有八九就是这里没填或填错。

2.3 位号：让 AD 自己数

  画完图再手工给 R1、C1 编号是自找麻烦。工具»标注»原理图标注(A)（快捷键 T A）打开标注对话框，能设定处理顺序（先上后下、先左后右等），一键全图编号；同一菜单下还有 重置原理图位号、静态标注（锁定位号不参与重编）、反向标注（从 PCB 回写原理图）。

  顺带一个定位技巧：J C 打开"元件位号"对话框，输入位号就能直接跳到那个器件——图大的时候比在工程树里翻页快。

2.4 让图面更干净：Comment = =Value

  默认每个元件旁边会显示 Comment（注释）字段，通常是"100k"这种手填值。手填的问题是改值要改两处：Value 改了，Comment 忘了改。

  解决办法是把 Comment 填成参数表达式 =Value。这样元件旁显示的就是 Value 参数本身，改 Value 自动同步，图面既简洁又不会出现"标着 10k 实际 100k"的事故。

2.5 丝印、阻焊与焊盘的几何关系

  画封装时有两条硬约束，早记住能少返工：

  第一，阻焊开窗要比焊盘大一圈。 紫色那圈就是 Solder Mask，比铜盘略大，不然板厂的阻焊油会压到焊盘上导致上不了锡。

  第二，顶层丝印不能压在阻焊开窗上。 所以 Top Overlay 画的器件外形框必须比焊盘大一档；如果只是想画个等大的装配轮廓，就把它放到机械层（比如 Mechanical 2），机械层没有这个限制。

  这两条在库阶段粗调就行，最终统一在 PCB 阶段用 Solder Mask Expansion 规则一刀切（见第 9 章《设计规则与 DRC》），不必在库里死抠 0.1mil。

2.6 画封装/3D 时"老是自动吸附"怎么办

  画封装边框或 3D 体时，光标总是被吸到附近的焊盘、顶点上，线条还老是被角度约束"掰"成 45°。按住 Ctrl 再继续绘制，就能临时关闭吸附与角度约束，微调时特别好用。

三、原理图模板、编译与 ERC

  原理图画完不等于完事。图纸规范（模板）、页序（页编号）、电气正确性（编译 + ERC）是三件必做的事。

3.1 图纸模板 .SchDot

  模板决定图框、标题栏、公司名、图纸尺寸这些"门面"。做法很土但有效：新建一张原理图，把图框和标题栏画成想要的样子，然后另存为 Advanced Schematic template (*.SchDot)。

  调用：设计»模板»Load from File...，选中 .SchDot 即可。套用的范围很关键——更新模板 对话框里可以选 仅该文档 / 当前工程的所有原理图文档 / 所有打开的原理图文档，参数作用还能选 不更新任何参数 / 仅添加模板中存在的新参数 / 替代全部匹配参数。

  我的一般选法：当前工程所有文档 + 仅添加新参数。这样图框统一了，自己已经填好的参数也不会被模板里的空值覆盖。

3.2 页编号与位号是两套命令

  多页原理图要在标题栏写 Sheet 1 of 6，靠的是 工具»标注»图纸编号(I)，不是元件标注那一条。同一个 标注 子菜单里，原理图标注 管元件位号，图纸编号 管页序，别混。

3.3 编译：让 AD 先替你挑错

  编译（Validate）不会改图，它只是按 ERC 矩阵把整张图"过一遍筛子"，把所有可疑点写进 Messages 面板。入口是 Projects 面板里工程名右键 → Validate PCB Project。

  编译完双击 Messages 里的条目，AD 会交叉探针跳到出错位置。Shift+Ctrl+F3 / Shift+Ctrl+F4 可以在消息之间上下穿行。如果某一类告警你根本不关心，就去 Project Options»Error Reporting 把它的报告格式改成"不报告"，而不是每次编译都对着一屏红叉发愁。

3.4 两类最高发的 ERC 报错

  第一类：悬空引线当网络名用。 器件符号上引出的那条黑色短线没有电气特性，它只是个"引脚图形"。必须在它末端接上导线或网络标签，网络才成立。

  这类错误编译时表现为 Nets with only one pin、Unconnected objects in net，看着像"我明明连了啊"——其实连的是视觉，不是电气。

  第二类：端口（Port）方向与层次图不配对。 端口有四种电气类型，选错了 ERC 一定报：

端口类型 含义 ERC 行为
Unspecified 未指定 不定义方向 不校验流向；层次图里混用容易告警，适合电源/GND
Output 输出 驱动端 可驱动 Input/Bidirectional，不能被别人驱动
Input 输入 接收端，无驱动能力 该网络必须有驱动源，否则报 no driving source
Bidirectional 双向 可收可发 I²C / SPI / USB / 单片机 IO 常用

  层次原理图的配对规则是"方向相反"：子图的 Port 是 Output，顶层对应的 Sheet Entry 就要设成 Input；Port 是 Input，Sheet Entry 就要是 Output；Bidirectional 对 Bidirectional。这一点想通了，no driving source 这类报错基本绝迹。

3.5 编译通过之后，库才"活"过来

  自己建的元件，建完不等于能用。必须在工程名上右键 Validate PCB Project 编译一次，AD 才会把库信息纳入工程索引，Components 面板里才搜得到。

  然后从 Panels»Components 打开面板，把左上角的库源下拉切到 FILE-BASED LIBRARIES，选中本工程的 .SchLib，就能像用官方库一样双击放置了。

四、原理图 → PCB：导入与交互定位

  原理图编译干净了，接下来是把它"搬"到 PCB。这一步的坑不在操作难度，而在方向和耐心。

4.1 两个方向，别点反

  PCB 界面的 设计 菜单里，最上面两条命令长得几乎一样，方向却完全相反：

命令 方向 什么时候用
Design » Import Changes From <工程>（导入变化） 原理图 → PCB 99% 的情况：原理图改完，同步进 PCB
Design » Update Schematics in <工程>（更新原理图） PCB → 原理图 在 PCB 里改了位号/网络，反向回写原理图

  我的记法是：“Import 从工程导进来”——工程（原理图）是源头，“进来"的是 PCB。点反了不会报错，但会让你在错误的那一侧白改半天。官方对这套双向同步机制的说明见 原理图与 PCB 之间的设计变更。

4.2 执行两遍，直到 No Differences

  点 Import Changes 会弹出**工程变更指令（Engineering Change Order）**窗口，列是"更改 / 动作 / 受影响对象 / 受影响文档 / 状态”。流程是固定的三步：

  1. 点 验证变更 —— AD 先"空跑"一遍，把能不能做、有没有错列出来；
  2. 点 执行变更 —— 真正把改动写进 PCB；
  3. 再看一遍，再执行一遍。

  第 3 步是最容易被跳过、也最关键的一步。第一遍执行会"藏"住部分问题：有些错误是由前一批改动派生出来的，第一遍跑完才暴露出来。所以要反复"验证 → 执行"，直到所有行全变绿。

  什么时候算同步完成？当比较结果弹出 Comparator Results (No Differences) / No Differences Detected 时才算真的对齐。看到这个框，说明原理图与 PCB 的元件、网络、类成员已经完全一致。

4.3 三类导入报错，对症下药

  导入报错看起来五花八门，其实只有三类根因：

报错信息 根因 怎么改
Footprint Not Found SOP-8 元件没填封装 / 封装名不匹配 / 库路径没匹配 用封装管理器统一指定，或把库加入工程
Unknown Pin: Pin P1-1 封装焊盘号与符号管脚号对不上 改封装焊盘编号，或改符号 Pin Designator
Failed to add class member 类成员添加失败（多数是该器件本身有错） 先解决这个器件的封装/Pin 问题再重跑

  上图里的 Footprint Not Found SOP-8 与成片的 Unknown Pin 就是典型：前者是"封装还没安排"，后者是"封装有了，但焊盘号和符号对不上"。先看"消息"列，不要盲目重导——重导一百遍也不会自己变对。

4.4 交叉选择：原理图与 PCB 的"连坐"

  布局时最常用的动作是"原理图上点一个器件，PCB 上立刻高亮它"。这叫交叉选择（Cross Select），要三个条件同时满足：

  ① 两边都打开开关。 在原理图和 PCB 里分别执行 交叉选择模式（右键菜单里，快捷键 Shift+Ctrl+X）。只开一边，另一边不会有反应。

  ② 选对"交叉的对象类型"。 在 优选项»System»Navigation»交叉选择的对象 里勾选 元件 / 网络 / Pin脚。默认通常只勾了元件，所以"我在原理图点了网络，PCB 没反应"。

  ③ 找不到就用交叉探针。 快捷键 T C（交叉探针）是"强制跳转"：在 PCB 里对着某个器件按 T C，会跳到原理图里对应的符号；反过来也行。

4.5 网络级交叉选择：顺手把网络类建了

  把交叉对象设成"网络"之后，用法会多一步：在原理图里点中某条网络 → 切到 PCB，在空白处右键 → 网络操作：

  • 第一次：选 根据选择的网络创建网络类，AD 会新建一个类并把这条网络放进去；
  • 以后：选 Add Selected Nets to NetClass，把网络追加到已有类里。

  这条链路的价值在于：网络类一建好，就能立刻用规则去约束它（加大线宽、单独间距），后面第九章《设计规则与 DRC》和第十章《网络分类、铺铜与布线》会反复用到。

五、布局与编辑的高效操作

  PCB 里 80% 的时间花在"摆"和"改"上。这几个键位能让这段时间缩一半。

5.1 T O L：把一堆器件排成矩阵

  框选一堆器件，按 T O L（工具 » 器件摆放 » 在矩形区域排列），AD 会让你画一个矩形，然后把选中器件按行列均匀排进这个矩形。刚导入 PCB 时所有器件堆在一起，用它先"码齐"，再逐个摆位，效率极高。

5.2 E A：特殊粘贴与阵列粘贴

  要复制一排一模一样的焊盘/元件（比如排针、测试点阵列），用 Ctrl+C / Ctrl+V 一个个贴太慢。正确姿势是 E A（编辑 » 特殊粘贴）：

  • 在 特殊粘贴 对话框里可以勾 粘贴到当前层、保持网络名称、重复位号、添加到元器件类；
  • 点 阵列式粘贴…，在 设置粘贴阵列 里填对象数量与 X/Y 轴间距，一次生成一整行。

5.3 M X：按偏移量精确移动

  M X（移动 » X/Y 偏移）弹出"获得 X/Y 偏移量"对话框，填 X、Y 后确定，选中对象就精确平移这个距离。做等距排列、把器件对到某个坐标上时，比鼠标拖准得多。

5.4 L：移动中翻层

  把器件从顶层放到顶层……不对，放到底层，不需要删了重放。拖动元件的过程中按 L，它就翻到另一面，丝印自动镜像。

5.5 N：飞线太多？先关掉

  布线时满屏飞线，眼睛根本分不清。N 打开飞线菜单：显示连接、隐藏连接、显示跳线、隐藏跳线，每项还有"全部 / 网络 / 器件"的范围子菜单。布一块区域时先把它周围的飞线藏掉，视觉立刻清爽。

5.6 拉长走线：抓端点，不是拖中间

  这是被问得最多的一个"小问题"：为什么我拖线只能整体平移，不能拉长？

  因为你拖的是线段中间。正确做法是：先单击选中走线，线的两端会出现白色小方块控制点，按住左键拖这两个端点，才是拉伸/缩短；拖线段中间永远是平移整条线。如果看不到控制点，多半是视图太小，或者这条线被锁定了（双击打开属性，取消 Locked）。

  觉得鼠标不稳，就用命令：E M A（编辑 » 移动 » 拉伸走线），稳定且可重复。

5.7 选择过滤器：只选你想选的东西

  改丝印时最烦的是"框选一下，走线焊盘全被选中了"。先在 Selection Filter 面板里只勾 Texts，再框选，就只会选中文字。

5.8 高亮一条网络，看清它走到哪

  Ctrl+左键 点击某个焊盘/走线，整条网络会亮起来，其余对象变暗；此时按住 Shift 移动鼠标，同一网络在其他区域的分段也会跟着亮。看完按 Shift+C 清除高亮——这个键同时也清过滤器，非常好用。

5.9 测量：先解决吸附，再谈精度

  Ctrl+M 是两点测距，但它准不准，取决于上一节说的捕捉设置。测焊盘中心距之前，先 Ctrl+E 打开捕捉选项，勾上 Pad Centers，否则光标根本不会吸附到中心点，量出来的数永远是"差一点"。

  状态栏会实时显示坐标与当前尺寸标注，量完随手记下，比事后猜靠谱。

六、Off-grid：讨厌但可控的警告

  编译原理图时经常刷出一屏 Off grid R44 at 8270mil,5163mil。这类警告最容易两极分化：有人完全无视，有人被它逼到重画。

6.1 它到底是什么

  off-grid object 指的是电气对象（端口、引脚、电气端点）的热点不在捕捉栅格上。注意关键词是"电气对象"——装饰性的线条、注释文字不在栅格上完全无所谓。

  它的性质是：不会导致出不了网表、不会影响布线，网表通常是正确的。但它会埋雷：

  1. 肉眼看着"连上了"，实际没连上，走到 PCB 才发现丢网络；
  2. 层次原理图里 Sheet Entry 与子图 Port 对位时更容易识别异常；
  3. 后续批量修改、阵列复制端口时，偏移栅格的对象容易出现诡异的连通性问题。

6.2 两种处理方式

  方式一：把对象吸附回栅格（治本）。 在 Messages 里选中一条警告，AD 会跳到对应器件；右键 → 对齐»对齐到栅格上，器件就自动归位。

  但这个方法有个副作用：如果原理图已经画完了，归位会把导线拉开，出现一堆断点，得重新连线。所以它只适合"图还没画完"的阶段。

  方式二：改 ERC 报告级别（治标）。 原理图界面右键 → 工程选项 → Error Reporting，把 Off-grid object 的报告格式改成"不报告"，下次编译就不再刷屏。

  我的实际做法是：画图阶段规范栅格（放器件 100mil、连线 10mil），从源头少产生；图已完成后如果警告不多就直接忽略，多了才考虑改报告级别。不要为了消灭警告去重画一张已经验算过的图。

七、ROOM：多通道布局的"复制粘贴"

  前面都是"画一块板"，这一章是"画很多块一样的板"。当一张板上有 N 路完全相同的电路（多路传感器、多路功放、多路 LED 驱动），手排第二、第三路纯属浪费生命——ROOM 就是 AD 给多通道设计准备的复用机制。

7.1 先看一遍完整录屏

  文字再详细也不如看一遍手速。下面这段是完整的 ROOM 操作过程（建 Room → 排一路 → 对通道号 → 拷格式），建议先看完再读后面的八步。

（点击画面开播，播放后点右下角全屏按钮可放大；原片 4K、77MB，首次可能要缓冲几秒）

  如果上面的播放器一直转圈或加载不出来，点这里直接打开视频，也可以用浏览器另存到本地再看。

7.2 它到底复用了什么

  一个 ROOM 圈住的是"一路通道的全部器件"。AD 复用的对象不只是位置，而是整组器件相对布局 + 朝向 + 位号注释格式 + Room 外形尺寸 + 网络连接。也就是说，第二路你只需要"确认一下"，不需要"再排一遍"。

7.3 八步流程

7.3.1 准备：建 Room 与批量编辑

  第一步：确认多通道结构。 原理图里通道通常以 MIC-信号采集1[3B]、MIC-信号采集2[2D] 这种带通道编号的 Room 名重复出现，PCB 侧对应 ROOM1、ROOM2。

  第二步：给一路通道建 Room。 框选一路通道的全部器件 → 设计»Room(M)»从选择的器件产生矩形的Room(I)。

  执行后画面上出现带名字的 Room 框（RoomDefinition、RoomDefinition_1），框内是这一路的器件阵列。

  第三步：调出 PCB List 面板。 在面板停靠区右键，从长长的面板清单里选 PCB List——它是"表格化的 PCB"，能批量看、批量改属性。

  第四步：让表格可编辑。 PCB List 默认只读，点一下 Edit 列头，出现勾选框后才允许直接改单元格。

  同时把过滤范围设成 selected objects，保证后面的批量修改只作用于选中的这个 Room，不会误伤另一路。

  第五步：把视图"瘦身"。 View Configuration»Objects»仅显示，只勾 Component，把走线、焊盘、文本全藏掉。这样 PCB List 里只剩器件行，排得下、看得清。

7.3.2 对齐：排序、基准与通道号

  第六步：按位号排序，建立对齐基准。 点 Designator 列头升序，两路通道的器件就按 C → D → Q 的顺序一一对位。

  排布时有个小技巧：把成组的电容排在最前面当"参考尺"。同封装、同数量、成片出现的电容，是两路之间最容易对齐的基准，基准对上了，其余器件的相对位置就有参照。

  第七步：核对/复制 Channel Offset（通道号）。 这是全流程的命门，下一小节单独讲。

7.3.3 复用：拷贝 Room 格式

  第八步：执行拷贝。 设计»Room(M)»拷贝Room格式(C)，先点源 Room，再点目标 Room。

  最后在 确认通道格式复制 对话框里定稿：

  • 源Room / 目标Room 确认无误；
  • 勾 复制元器件布局、复制位号&注释格式、复制布线的网络、复制Room尺寸/外形、Copy Room Orientation；
  • 通道到通道元器件匹配 选 Match Components By Channel Offsets；
  • 移除受影响的连接 选 Contained parts of connections only；
  • 仅完全被包含的对象 保持默认。

7.4 Channel Offset 才是真正的"命门"

  为什么 ROOM 拷贝有时"搬错器件"？因为 AD 靠 Channel Offset（通道号） 来判断"源 Room 的 R1"该对应"目标 Room 的哪个电阻"。通道号对不上，布局就会搬到错误的位置上，越看越像"随机乱排"。

  所以流程里有一道验收：当两个 Room 的器件位号一一对应、Channel Offset 连续对齐时，才可以执行拷贝。

  这一步的实操就是在 PCB List 里盯住 Channel Offset 列，把源 Room 每个器件的通道号按功能复制到目标 Room 的对应行。看着枯燥，但它是"一劳永逸"与"返工一晚上"的分界线。

八、层叠、板框与负片

  进入 PCB 的第一件事不是布线，是"把地基定下来"：板子几层、每层干什么、外形多大。

8.1 先记层分工口诀

  AD 的层名又多又像，但日常真正要手动画的只有三类，其余都自动生成：

8.3 正片与负片：AD 里最容易搞混的一对概念

  在叠层表里插入层时，Signal 和 Plane 这两个类型决定了这一层的"成像逻辑"：

  • Signal = 正片：画什么就有什么铜，走线和铺铜的地方保留铜。
  • Plane = 负片（内电层）：默认整层满铜，画线等于挖掉铜（做隔离）。

  把两者的差别列清楚：

对比项 正片层 Signal 负片层 Plane（内电层）
本质 画什么有什么铜 默认满铜，画图形＝挖铜
能否走线 可以（Top/Bottom 都是正片） 一般不走线，只做电源/地平面
大面积铜 需要 Polygon Pour 铺铜才生成 天生整片铜
连接方式 由 Polygon Connect Style 控制 由 Power Plane Connect Style / Power Plane Clearance 控制
典型用途 顶层/底层信号层 多层板内层 GND / POWER
Gerber 输出有铜区域 输出无铜区域

  一句话记住：正片"画线才有铜"，负片"画线就挖铜"。四层板最经典的配置就是 Top/Bottom 用正片走信号、中间两层用负片做 GND02 / PWR03。

8.4 板框：画在 Mechanical 1

  板框画错层是新手常见事故。标准做法只有一个：画在 Mechanical 1。板厂就是拿这一层的外形线去铣边、开料的。

  画完闭合线条后，框选它，执行 设计»板子形状(S)»按照选择对象定义(D)（D S D），线条就变成了真正的 Board Shape——之后铺铜、3D 渲染、导出 STEP 都依赖它。

  反过来也支持：板子形状»根据板子外形生成线条(P) 把已有板形反向画成线条，方便修改后重新定义；板内开槽用 板子形状»定义板切割(C)，或画好形状后用 T V B 转成切割槽。

8.5 DXF 导入：结构工程师给的外形

  外壳是结构画的，板框从 DXF/DWG 导入。入口：文件»导入»DXF/DWG，弹出 Import from AutoCAD。这个对话框有四个必看项：

选项 取值 原因
Scale mm 图纸单位是 mm，选错整体缩放；右侧红字尺寸要和图纸标注对得上
Drawing Space Model 取模型空间，不是图框
Blocks Import as primitives 导成图元，便于后续编辑/转板框
Layer Mappings 统一映射到同一机械层 同一张图的线必须在同一层，否则选不中、转不了板框

  最容易踩的一脚在 Layer Mappings：源 DXF 的层名（TOPLAYER、MECHANICAL1、BOTTOMSOLDER…）要统一映射到某一个机械层（Mechanical 2/3/10 都行），但不要占用 Mechanical 1——那一层要留给板框。

  映射配好可以 Save Settings 存起来，下次同类型结构图直接 Load Settings，省掉一遍配置。

九、设计规则与 DRC

  规则是 PCB 的"法律"。前期不立规矩，后期 DRC 会一次性把你打回原形。

9.1 规则的入口与骨架

  设计»规则(R)…（D R）打开 PCB 规则及约束编辑器。左边是一棵树，按 Electrical / Routing / SMT / Mask / Plane / Testpoint / Manufacturing / High Speed / Placement / Signal Integrity 分类；右边是具体规则，每条规则有两个作用域 Where The First Object Matches / Where The Second Object Matches。

  常规板子其实只用得上六类：间距、线宽、过孔、阻焊、铺铜、差分。其余是高速与特殊工艺场景再补。

  这六类对应的"数字配方"，我整理成一张表（单位全部是 mil，1mil ≈ 0.0254mm）：

项目 建议值 说明
安全间距 Clearance 6mil 走线/焊盘/过孔交叉全 6
铜皮与走线间距 10mil Clearance 矩阵里 Copper 行/列单独设 10
铺铜到板框 20mil Board Outline Clearance 统一 20
过孔 孔径 12 / 外径 24 min = max = preferred
阻焊外扩 2.5mil 阻焊桥要求 4mil
负片反焊盘 6mil 常用 5~9mil
差分对（USB 90Ω） 宽 5 / 距 9 最大未耦合长度 500mil
丝印到阻焊/焊盘 2mil Silk To Solder Mask Clearance
丝印到丝印 2mil Silk To Silk Clearance

  这些数值全以 mil 为单位。规则对话框的标题栏会标注当前单位（[mil] 或 [mm]），改单位按 Ctrl+Q——注意在多处界面里 Q 是无效的，只能用 Ctrl+Q。换算记住两个数：1mil ≈ 0.0254mm，0.254mm = 10mil。

9.2 十二条规则，按类型分组

  素材里那 12 张"规则设置建议"，如果按 1~12 的顺序看会很乱（Electrical → Routing → Mask → Plane → Manufacturing 来回跳）。我按规则类型重新组织，一条条过。

9.2.1 Electrical：先保证"该连的都连上"

  Un-Routed Net（未布线网络）规则是性价比最高的一条：勾上"检查不完整连接"，AD 会把所有"该连但没连"的网络标出来，比肉眼找断线可靠一百倍。

  Clearance（安全间距）是核心。它分"简单/高级"两种填法，高级模式是一张对象类型交叉矩阵：Track × SMD Pad × TH Pad × Via × Copper × Text × Hole。图中做法是其他全 6mil，只把 Copper 行/列单独提到 15mil——这就是"铜皮的间距可以更宽松"的落地方式。

  “铜皮与走线统一 10mil"就是同一张表里把 Copper 行/列改成 10，其余保持 6。用矩阵而不是另建一堆规则，维护起来清爽得多。

  板边间距单独有一条 Board Outline Clearance：它管"对象到板框外缘 / 开槽边缘 / 分割屏障"的距离，建议 20mil。铺铜离板边太近，铣边时容易露铜、毛刺。

9.2.2 Routing：线宽与过孔

  Routing Via Style 控制过孔的外径与孔径，用"最小 / 最大 / 优先"三组值。图上是最保守也最省事的填法：外径 24mil、孔径 12mil，三组全部一致——没有"优先值"的弹性空间，成本与钻孔就固定下来，不会出现一堆奇怪的孔径。

  线宽规则可以按 Net Class 作用域批量设。做法：在 Width 上右键 新规则…（或 重复的规则），把 Where The Object Matches 改成 Net Class，选中 Analog Signal / PWR 之类，再填宽度。

  差分对另有一条 Differential Pairs Routing：作用域选差分对类，宽度/间距成对填（USB 90Ω 场景下是宽 5mil、距 9mil），再给一个"最大未耦合长度"限制（500mil）。

9.2.3 Mask：阻焊与过孔盖油

  Solder Mask Expansion 控制阻焊开窗比焊盘大多少。图上顶层/底层各 2.5mil，两层可以"链"起来同值。要注意板厂的阻焊桥最小宽度（通常要求 4mil 级别），外扩太大反而会把相邻焊盘的阻焊桥吃掉。

  “过孔盖油"是个高频需求，做法是再加一条 Solder Mask Expansion 规则，用 Custom Query 把作用域锁到 Via：Where The Object Matches 选 Custom Query → 点 查询构建器 → Object Kind is → Via。

9.2.4 Plane：正片与负片的连接

  负片层的"反焊盘”（Anti-pad）由 Power Plane Clearance 控制。常用 5~9mil，取 6mil 是个均衡值：太小容易击穿/加工困难，太大浪费铜、影响载流。

  正片层的铺铜连接方式在 Polygon Connect Style 里设：Direct Connect（实心全连）、Relief Connect（十字辐条）、No Connect（不连）。图中选的是 Direct Connect。

9.2.5 Manufacturing：丝印类检查

  丝印最容易在装配时"糊掉”，所以有两条专门规则：Silk To Solder Mask Clearance（丝印到阻焊开窗/露铜，图中 2mil）和 Silk To Silk Clearance（丝印到丝印，图中 2mil）。前者可以用 IsPad 之类的查询把作用对象限定到焊盘。

9.3 优先级：规则"明明设了却不生效"的真凶

  这是我在规则上踩得最深的一个坑：勾了过孔盖油，出图还是开窗。不是查询写错，是优先级。

  AD 匹配规则的逻辑是：同一规则类型内部，按优先级从上往下比，第一条命中的就停止。软件自带的 All 作用域默认规则覆盖面最大，如果新加的 IsVia 规则排在它下面，就永远轮不到。

  上图里的排序是正确示范：Analog（12mil，作用域 InNetClass('Analog Signal')）→ PWR（15mil，InNetClass('PWR')）→ Width（6mil，All）。越具体越靠前，最笼统的默认规则永远垫底。

  几个要点：

  1. 优先级是按规则类型分表的。改好 Width 的排序，不影响 Solder Mask 的排序，每类都要单独确认。
  2. 对话框底部有 优先级(P)… 按钮，列表里用 增加优先级(I) / 降低优先级(D) 调整。
  3. 排查顺序：作用域是否命中 → 是否勾了启用/在线 → 优先级是否压过默认规则。三者依次排除，不要一上来就怀疑软件。

  规则树 Plane 下面三条要分清归属：

层类型 管连接 管间距

  Power Plane Connect Style 的 Relief Connect 可以细调外扩、空气间隙、导体宽度、导体数量——图上常见的一组是外扩 20mil、空气间隙 10mil、导体宽度 10mil、4 根导体。

9.5 DRC：出图前的最后一道闸

  入口：工具»设计规则检查(D)…（T D R）。

  打开的是设计规则检查器。左侧是规则分类，右侧每个规则有**“在线"和"批量"两列**：

  • 在线（Online DRC）：布线时实时检查，错了立刻出现绿色/红色标记；
  • 批量（Batch DRC）：出图前一次性全板跑一遍，生成报告。

  只勾你真正在乎的项，能大幅减少噪声。丝印类我一般只勾 Silk To Silk Clearance、Silk To Solder Mask Clearance、Minimum Solder Mask Sliver、Board Outline Clearance 这四条。

  跑完点 运行DRC (R)…，结果进 Messages 面板，逐条按"规则名 / 类别 / 位置"定位修改。已知可接受的（比如测试点开窗）用 T M 复位错误标志清掉，而不是长期无视红叉——无视久了就再也分不清哪个是真错。

十、网络分类、铺铜与布线

  规则是"法律”，网络类是"户籍"。先给网络分好类，规则才能精准打击，这是效率、也是可维护性的关键。

10.1 从建类到约束的完整链路

  ① 建类。 PCB 界面 设计»Classes…（D C）打开对象类浏览器，在 Net Classes 下新建一个类（比如 PWR），把电源网络从左侧"非成员"移到右侧"成员"。

  类不只有网络类。同一个浏览器里还有 Component Classes、Layer Classes、Pad Classes、Polygon Classes、Differential Pair Classes，分门别类，互不干扰。

  ② 看清类成员。 打开 PCB 面板，对象选择器选 Nets，把左上角模式从 Normal 改成 Mask——之后点类名，只有该类成员会高亮，其余全部变灰，肉眼就能核对"我到底把哪些网络归进来了"。

  ③ 上色。 给关键网络（电源、模拟、差分）分别设颜色，然后 F5 开关"颜色显示"。上过色之后，布线时一眼就能看出"这条是不是电源"。

  ④ 约束。 类建好之后立刻回到 设计»规则，为这个类建 Width / Clearance 规则——这就是上一章"优先级"要处理的对象。

  ⑤ 差分对要单建。 差分对不走网络类，而是在 PCB 面板切到 Differential Pairs Editor，用 从网络创建 生成，之后才能被 Differential Pairs Routing 规则引用。

10.2 铺铜：从画到修

  铺铜不是"画个框按一下就完事"，画完之后 80% 的工作在修。

  改属性。 选中铜皮，右侧 Properties 面板就是它的全部：网络、层、Solid/Hatched、孤岛过滤、颈宽过滤、Arc Approximation……点 Modify 可以改轮廓，点 Repour 重铺。

  修形状。 铜皮的边角最好是钝角。直角、锐角在蚀刻时容易残留，载流也不均匀，选中后 Modify 把尖角改成钝角是常规操作。面板顶部如果提示 Polygon not poured，必须先 Repour，否则看到的是旧铜。

  挖掉不要的铜。 有两种办法：放置»多边形铺铜挖空 直接在铜皮上挖，或者先画个圆/矩形，再用 T V T（转换 » 从选择的元素创建非铺铜区域）把它变成禁止铺铜区。

  由板框生成铜皮。 想让铜皮贴着板框走，先在 Mechanical 1 选中板框轮廓，再 工具»转换»从选择的元素创建铺铜，铜皮外形就直接沿用板框。

10.3 “铺了不显示"的四步排查

  这是铺铜里最经典的问题：明明画了框，就是没铜。按顺序排查：

  1. 取消勾选 Remove Islands Less Than（默认 2500 sq.mil）——小铜块被当孤岛删了；
  2. 取消勾选 Remove Necks Less Than（默认 6/10mil）——窄颈被当"死铜"删了；
  3. 点 Repour（或选中网络按 Shift+B）重铺；
  4. 检查框内有没有 Keep-out / 挖空阻挡。

10.4 全连接还是十字连接

  焊盘/过孔与铜皮的连接方式只有三种，选错了要么焊不上、要么载流不够：

方式 表现 适用
Relief Connect（十字/热风焊盘） 4 根辐条 插件焊盘、需要手工焊接的孔，散热好焊
Direct Connect（全连接） 实心直连 大电流、低阻抗需求的过孔/焊盘
No Connect 不连 特殊隔离

  判断标准其实很朴素：要人焊的孔用十字，要过大电流的用过孔全连。图上这组对比里，十字连接有明显辐条，全连接则是实心一片。

10.5 缝合地过孔：两层板的救命稻草

  地平面的完整性，在两层板上是最脆弱的。走线横穿过去，GND 铜皮就被切成一条窄通道，两边的地"通而不畅”，回流只能绕远路。

  解决办法就是缝合地过孔（Stitching Via）：在两个地岛之间打一排过孔，让回流从另一层就近穿过去，把回流环路缩短。

  别一个个手点，AD 有专门工具：工具»缝合孔/屏蔽»给网络添加缝合孔(A)…。

  弹出的 添加过孔阵列到网络 对话框，推荐这样填：

参数 推荐值
网络 GND
钻孔对 Top - Bottom（通孔）
过孔样式 简易的（Simple）
孔径 / 盘径 12mil / 24mil（≈0.3 / 0.6mm）
栅格 50mil，并勾 错开交替的过孔阵列
默认过孔/焊盘间距 5mil
阻焊 来自规则的扩展值 + 强制顶层/底层全部盖油
约束区域 需要限定时勾选，再画区域

  这里补一个官方视角的约束：缝合孔的间距不是随便定的，工程上通常要求不超过最高有效频率对应波长的 1/20（λ/20），短截线长度同理；过孔围栏（shielding）则常用 λ/10~λ/20。50mil 这个经验值在多数中低速板上是安全的。相关说明见 过孔缝合与过孔屏蔽。

  如果只想在板子某个区域打孔（比如只在连接器附近），勾上 约束区域，AD 会让你先画一个区域，缝合孔只会落在区域里；配合 Via Template 还能复用固定的过孔样式，避免每次重填孔径盘径。

  另外要注意：4 层板有完整参考平面时，同样的"割裂"可以暂时容忍，但仍然是隐患；两层板就必须老老实实处理。

  最后别忘了清掉长条形的残留铜皮——它等效于一根天线，既辐射又容易在蚀刻时翘起，用铺铜挖空挖掉。

10.6 布线：几个真正省时间的动作

  多路（总线）布线。 布线»交互式总线布线(M)，快捷键 U M，可以一次拉出一组并行线，排线、数据总线特别省事。

  走线中按 Space 换方向。 空格不是"确认"，而是循环切换拐角/路径模式（45°、90°、圆弧等），走线卡住时按一下往往就顺了。

  Shift+R 管"能不能斜着走"。 它循环切换 Orthogonal（只能横平竖直）/ 45 Degree（直角+45°）/ Any Angle（任意角）。状态栏会显示当前模式，确认一下再动手。差分对和等长线不要随便用任意角，普通信号线优先正交——否则后期改线、算长度都会很难受。

  Shift+W 换线宽。 布线中按 Shift+W 弹出 Choose Width 列表，mil/mm 双单位对照，勾 Apply To All Layers 可对整条线所有层生效。

  布线顺序。 模拟信号优先且尽量不打孔（过孔是阻抗突变点），再走其他信号，电源与 GND 最后处理，模拟线走完记得包地。

11.2 Gerber：一层一个文件

  入口：文件»制造输出(F)»Gerber Files。这个子菜单其实是"制造输出总店"，NC Drill Files、ODB++、IPC-2581、Test Point Report、Mask Set 全在里面。

  Gerber Setup 的关键设置：

  • Units 选 Inches，Decimal 选 0.1 mil（精度）；
  • 输出命名选 filename.*(gtl, gbl, gto...)，一个文件一层，板厂好识别；
  • 勾 Include unconnected mid-layer pad、Generate Reports；
  • Plot Layers 下拉里点 Select Used，AD 会自动勾上实际用到的层。

  点 Select Used 之后，机械层（GM1/GM2/GM3/GM6/GM13/GM15）会被自动补勾；而 Keep-Out Layer、Top/Bottom Pad Master 属于 Other Layers，默认不勾也不该勾。

  输出完 AD 会自动生成一个 CAMtastic1.Cam，在面板里打开 CAMtastic 就能逐层核对：板框（红）、铜层（蓝）、丝印与阻焊。这一步是"自检"，比等板厂回邮件快得多。

11.3 钻孔：精度要和 Gerber 对齐

  入口：文件»制造输出»NC Drill Files，必须在 Gerber 之后做。

  NC Drill 设置 里三件事：

  • 单位 英寸(I)；
  • 格式 2:4（0.1mil 分辨率，正好与 Gerber 的 0.1 mil 对齐；2:3 只有 1mil 分辨率）；
  • 摒弃尾数零(T)、参考相对原点(V)，勾 优化变更位置命令(O)。

11.4 坐标文件：贴片厂要的那张表

  入口在"装配输出"里，不在"制造输出"：文件»装配输出(B)»Generates pick and place files。

  拾取文件设置 里至少勾这几列：Designator、Comment、Layer、Footprint、Center-X(mil)、Center-Y(mil)、Rotation、Description。单位选 英制(I)，格式按贴片厂要求选 文本(T) 或 CSV(Q)；底层元件是否 Y-翻转底层元件，要跟产线确认。

11.5 IPC 网表：容易找错门的那一个

  到处找 IPC-2581？那个不是飞针测试用的。IPC-D-356A 网表的真正入口是 制造输出»Test Point Report。

  在 Fabrication Testpoint Setup 里把 报告格式 选成 IPC-D-356A(I)，测试点层勾顶层+底层，单位英制，坐标用 参考相对原点——与坐标文件保持一致，否则贴片和测试对不上。

11.6 装配图：用智能PDF 出单色线稿

  装配图走的是打印路线，不是 Draftsman。入口：文件»智能PDF(M)…。

  第 1 页：选范围。 只要 PCB 的装配图就选 当前文档；想连原理图一起出就选 当前项目。

  第 2 页：要不要 BOM。 只出装配图就不勾 导出原材料的BOM表。

  第 3 页：打印设置（关键）。 顶层 TopAssembly Drawing 不勾 Mirror；底层 BottomAssembly Drawing 要勾 Mirror；两层都包含 Top/Bottom Overlay + Mechanical 1；Designator 选 Print Physical Designators；区域 Entire Sheet。

  第 4 页：颜色模式。 PCB颜色模式 选 单色，质量 Medium (300 dpi)——线稿才是装配工人要的，彩色反而看不清位号。

  第 5 页：保存配置。 勾 导出后打开PDF文件，同时勾 保存设置到批量输出文件，生成 .OutJob——以后同类板子直接复用这套打印配置。

  出来的效果就是下面这两页：顶层正读，底层镜像，位号清晰。

11.7 BOM 与打包

  BOM 用 R I（报告 » Bill of Materials）打开物料清单对话框，可以拖列头分组、Preview 核对，再 Export... 导出 Excel/CSV。

  所有输出默认汇总在工程目录下的 Project Outputs for <工程名> 文件夹，同级还有 Project Logs、History、-BOM。打包发给板厂/贴片厂时，取这个目录即可。

十二、3D 视图与模型

  3D 不是花架子。装配干涉、连接器朝向、外壳高度，平面图看不出来，3D 一眼就露馅。

12.1 切换与旋转

  最快的是按 3 进 3D、按 2 回 2D。也可以在 Ctrl+D 打开的 View Configuration 里控制：3D 的 On/Off、2 or 3 开关、Projection（Orthographic 正投影 / Perspective 透视）、Show 3D Bodies（Shift+Z）、以及每层的透明度滑杆。

  翻转视角必须按住 Shift 再按右键，会调出轨道旋转球；只按右键是无效的，这是新手最常卡住的一步。

  想直接看背面，按 V B，一步翻面，比转半天快。

12.2 3D 模型从哪来

  四条来源：从别人的板子提取（D P 生成 PCB 库时会带着 3D）、自己用 3D元件体 画挤出体、从网上下 STEP 模型导入、或者直接用现成的超级库。

  从成品板提库时，3D 会跟着封装一起进库，这是最省事的一条路。

12.3 两个必踩的坑

  坑一：导入的 3D 模型颜色发黑/不对。 属性面板里的 Display»Override Color 如果被勾上，会用统一颜色覆盖模型自带的材质颜色。取消勾选即可还原。

  坑二：3D 模型老是自动吸附，微调不了。 这是 3D Body Snap Points（3D 模型顶点吸附）打开导致的，远距离就被"吸住"。把它关掉，保留 Pad Centers（对焊盘时还要用）；临时微调时按住 Ctrl 可以关闭全部吸附。

12.4 3D 到底值不值

  三个场景特别值：装配干涉（连接器、电池座、电解电容会不会撞外壳）、导出 STEP 给结构做整机装配、对照装配图检查"装反、装错面"。花半天给关键器件补 3D，往往能省掉一次打样返工。

结语：一份可以照着走的顺序

  把这篇日志压缩成一张"检查清单"，下次画板可以直接对：

  • 建库：优先 生成原理图库 / 生成PCB库 / IPC 向导，别从零画
  • 封装：封装管理器 全工程过一遍，确认每个元件都有封装
  • 原理图：套 .SchDot 模板、原理图标注 编号、图纸编号 排页
  • 编译：工程右键 Validate，把 ERC 清干净（悬空线、端口方向）
  • 导入 PCB：Import Changes From 反复执行到 No Differences
  • 层叠与板框：D K 定叠层，Mechanical 1 画板框后 D S D 定义
  • 规则：间距 6 / 铜皮 10 / 板框 20 / 过孔 12-24 / 阻焊 2.5，检查优先级
  • 网络类：D C 建类 → 规则约束 → 上色 F5 核对
  • 布局：T O L 码齐 → 分模块摆放 → ROOM 复用多通道
  • 布线：模拟优先不打孔 → 其他信号 → 电源地最后铺
  • 铺铜：修钝角、挖残铜、必要时缝合地过孔
  • DRC：T D R 批量跑一遍，该豁免的明确豁免
  • 输出：Gerber → 钻孔 2:4 → 坐标 → IPC-D-356A → 装配图 PDF → 打包

  最后说一句心里话：这些技巧单独看都很小，但画板的水平恰恰是这些"小事"堆出来的。快捷键快一点、规则准一点、导出的文件干净一点，最后交付的那块板子就靠谱一点。愿我们都能少返工，多打样。
